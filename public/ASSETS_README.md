# Assets opcionales

Coloca estos archivos en /public para activarlos:

- og-image.png    -> Imagen de vista previa al compartir el link (1200x630px recomendado)
- hero-poster.jpg -> Imagen de respaldo del video del hero, se muestra mientras carga o si el video no puede reproducirse (1920x1080px recomendado)

Si no existen, el sitio funciona igual, solo no se muestran estas imágenes.
